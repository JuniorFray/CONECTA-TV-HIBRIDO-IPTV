## ✨ Recursos

- **Login híbrido:** testa vários servidores em paralelo e conecta no primeiro que autenticar — o usuário só digita usuário e senha.
- **TV ao Vivo:** lista de canais com logos, categorias e reprodução nativa.
- **Filmes e Séries (VOD):** grade de pôsteres, capas/sinopses (TMDB), episódios por temporada.
- **Busca** global de canais, filmes e séries.
- **DNS anti-bloqueio** (DoH) para contornar bloqueio de operadora.
- Interface otimizada para **controle remoto** (Android TV) e **toque** (celular).

## 📲 Como instalar

1. Baixe o APK pelo link acima.
2. No aparelho, permita **"Instalar apps de fontes desconhecidas"** (Configurações → Segurança / do próprio instalador).
3. Abra o APK e toque em **Instalar**.
4. Abra o **Conecta TV** e entre com seu **usuário** e **senha**.

**Compatível com:** Android 7.0+ · Android TV · TV Box · celulares e tablets Android.
